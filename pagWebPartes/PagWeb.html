1. Etiquetas semánticas de HTML5

Sirven para estructurar la página web según la función de cada parte

Etiqueta Uso
<header> Encabezado principal
<nav> Menú con enlaces
<main> Contenido principal
<section> Sección de contenido
<footer> Pie de página

2. Texto y Enlaces

Uso de párrafos, texto resaltado y enlaces a otras páginas:

<p>Este es un párrafo con 
 <strong>negrita</strong>
 y <em>cursiva</em>.</p>
<a href="https://www.google.com"
 target="_blank">Ir a Google</a>
